# Benjamin & Stephanie | Save the Date

Static HTML, CSS, and JavaScript site. There is no build step or server-side code.

## Run locally

```sh
python3 -m http.server 5500
```

Open http://localhost:5500.

## Publish

The site is designed to live at the root of this repository. In GitHub, enable Pages for the `main` branch and `/(root)`.

## Privacy

The published site and this public repository are accessible to anyone with the link. The `noindex` metadata discourages search engines but does not restrict access. Do not add guest names, postal addresses, or other private information to the published files.
